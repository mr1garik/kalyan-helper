КАЛЬЯННЫЙ ПОМОЩНИК — СБОРКА ANDROID-ПРИЛОЖЕНИЯ НА WINDOWS
=========================================================

Что внутри архива
-----------------
android\          — Android-проект (его открываем в Android Studio)
node_modules\     — библиотеки Capacitor, нужны для сборки (ничего ставить не надо)
hookah\           — само приложение (то же, что на сайте)
capacitor.config.json, package.json — настройки проекта

Node.js на Windows НЕ нужен. Нужна только Android Studio.


1. Распакуйте архив
-------------------
Распакуйте kalyan-android.zip в папку C:\kalyan
Важно: путь короткий и без русских букв и пробелов. Из папок вроде
«Загрузки» или «Рабочий стол» сборка может не пройти.

После распаковки должна быть папка C:\kalyan\android


2. Установите Android Studio
----------------------------
1) Скачайте с https://developer.android.com/studio (кнопка Download Android Studio).
2) Запустите установщик, везде Next → Install.
3) При первом запуске:
   - Do not import settings
   - Standard → Next
   - на экране License Agreement выберите каждую лицензию слева → Accept → Finish
   - дождитесь, пока докачаются компоненты (10–15 минут) → Finish


3. Откройте проект
------------------
1) В Android Studio: Open (или File → Open).
2) Выберите папку C:\kalyan\android  — именно android, не C:\kalyan.
3) Если спросит «Trust project?» — Trust Project.
4) Подождите, пока внизу закончится «Gradle sync». В первый раз это
   5–15 минут: он докачивает нужные части.
5) Если Android Studio предложит обновить Gradle / Android Gradle Plugin
   (окно «Upgrade Assistant» или жёлтая плашка) — НЕ обновляйте,
   нажмите «Remind me later» / закройте.


4. Соберите APK
---------------
Меню Build → Build App Bundle(s) / APK(s) → Build APK(s)

Через 1–3 минуты справа внизу появится «APK(s) generated successfully».
Нажмите там «locate» — откроется папка с файлом app-debug.apk.
Путь: C:\kalyan\android\app\build\outputs\apk\debug\app-debug.apk


5. Установите на телефон
------------------------
1) Перекиньте app-debug.apk на телефон: Telegram «Избранное», Google Диск или кабель.
2) Откройте файл на телефоне → разрешите установку из этого источника → Установить.


6. Первый запуск на телефоне
----------------------------
1) Откройте «Кальянный помощник», разрешите уведомления.
2) ⚙️ Настройки → «🔔 Разрешить сигналы».
   Откроется системный экран «Будильники и напоминания» — включите
   переключатель для «Кальянный помощник» и вернитесь назад.
   В настройках должно быть: ✅ Уведомления  ✅ Будильники и напоминания
3) Отключите экономию батареи для приложения (важно на Xiaomi, Samsung, Huawei):
   Настройки телефона → Приложения → Кальянный помощник → Батарея →
   «Без ограничений».
4) Вставьте ключ Gemini в Настройках.
5) Перенесите данные с сайта: на сайте Настройки → 💾 Сохранить копию,
   в приложении Настройки → ⬆️ Загрузить.


Проверка сигналов
-----------------
Вкладка «Отдельные таймеры» → поставьте таймер на 1 минуту (✎ → 1) → ▶,
заблокируйте телефон. Через минуту должно прийти уведомление со звуком.


Если что-то пошло не так
------------------------
Сфотографируйте или скопируйте текст ошибки из Android Studio
(вкладка Build внизу) и пришлите — разберёмся.
